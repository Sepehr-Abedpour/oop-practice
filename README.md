#  Football Team Generator

یک پروژه ساده با زبان **Python** برای ساخت بازیکنان فوتبال و تقسیم تصادفی آن‌ها به دو تیم.

در این پروژه ابتدا بازیکنان به‌صورت Object ساخته می‌شوند، سپس با استفاده از `random.shuffle()` ترتیب آن‌ها به‌صورت تصادفی تغییر می‌کند و در نهایت ۲۲ بازیکن بین دو تیم **A** و **B** تقسیم می‌شوند.

## امکانات

* ساخت بازیکنان با استفاده از کلاس
* استفاده از **Inheritance**
* استفاده از `super()`
* تقسیم تصادفی بازیکنان بین دو تیم
* تشکیل دو تیم ۱۱ نفره
* نمایش نام بازیکنان و تیم مربوط به هر بازیکن

python football-team.py

## نحوه کار پروژه

ابتدا یک کلاس پایه به نام `Human` ساخته می‌شود که نام بازیکن را نگهداری می‌کند.

سپس کلاس `FootballPlayer` از کلاس `Human` ارث‌بری می‌کند و علاوه بر نام، یک ویژگی به نام `team` نیز دارد.

بازیکنان از روی لیست نام‌ها ساخته شده و داخل یک لیست قرار می‌گیرند.

بعد با استفاده از:

```python
random.shuffle(players)
```

ترتیب بازیکنان به‌صورت تصادفی تغییر می‌کند.

در نهایت ۱۱ بازیکن اول در تیم **A** و ۱۱ بازیکن بعدی در تیم **B** قرار می‌گیرند.
